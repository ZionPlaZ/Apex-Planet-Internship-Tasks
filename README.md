# Task 1: Foundation & Environment Setup

## Overview
This repository contains the technical deliverables, laboratory configurations, and command references for Task 1 of the ApexPlanet Software Cybersecurity & Ethical Hacking Internship Program.

## Repository Contents
- `task1/docs/Task1_Theory.md`: Comprehensive report covering the CIA Triad, Threat Landscape, OSI vs TCP/IP models, and Cryptographic Standards.
- `task1/docs/screenshots/`: Visual evidence of isolated lab deployment, OpenSSL cryptography execution, and Wireshark/Nmap runs.
- `task1/cheat-sheets/linux_cheatsheet.md`: Operational reference for Linux system administration, permissions, and network diagnostics.

## Environment Architecture
- **Hypervisor:** VirtualBox
- **Attacker Machine:** Kali Linux
- **Target Machine:** Metasploitable 2
- **Tools Verified:** Wireshark, Nmap, Burp Suite, Netcat, OpenSSL
